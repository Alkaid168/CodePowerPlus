状态：**组件层已确认，总览与知识树页面已实现；其余页面布局尚未设计**。最后更新于 2026-09-14。

> **权威基线：`FINAL_FRONTEND_TEMPLATE.md`。** 后续前端对话先读该文件；本 README 及其历史记录只作为补充，发生冲突时以最终模板为准。

本目录是后续所有前端对话的唯一视觉基准，不是应用运行代码。实现前先读本目录，不要根据旧版 `app/static` 继续扩展视觉。

## 设计方向

- 明亮、通透、克制，借鉴 macOS 的秩序感与 Xept 的紧凑边界。
- 以白色、黑色和标准灰阶为主，不使用渐变、彩色光晕或紫色装饰。
- 圆角参考 Xept：输入框与按钮 8px，卡片 12px，大面板 16px。
- 可编辑控件默认白底；只有禁用状态使用浅灰底。
- 动效强调即时反馈和物理感，不使用无意义的持续漂浮。
- 红、绿、橙只用于错误、成功、警告和判题结果，不参与普通装饰。

## 固定原则

1. **先读规范，再写代码。** 后续对话不得自创第二套圆角、颜色或动效。
2. **先继承，后扩展。** 新页面必须继承已确认的工作台外壳、组件和总览视觉基线，再设计自身布局。
3. **无渐变。** 所有表面使用纯色、细边框和低阴影。
4. **输入框默认灰边。** 所有可编辑输入框静止状态统一为 2px 灰色边框；只有用户正在输入时才切换为单层 2px 黑色边框，禁止常驻焦点样式和叠加 `outline`、`box-shadow`。
5. **可输入即白色。** 启用控件白底；禁用控件才使用浅灰底。
6. **状态色只表达状态。** AC、WA、TLE、错误、警告可以使用低饱和功能色。
7. **精确指针才触发悬停。** 悬停动画必须包在 `@media (hover: hover) and (pointer: fine)` 中。
8. **完整支持降级。** `prefers-reduced-motion`、`prefers-reduced-transparency` 和 `prefers-contrast` 随组件一起实现。

## 2026-09-14 全局页面模板约束（最新）

以下规则适用于所有页面，优先级高于旧页面结构：

1. 左上角使用 `/static/assets/codepowerplus-mark.png`。该资源由 `LOGO.png` 去除白底后裁切生成，必须保持透明背景。
2. 标志右侧只显示英文 `CodePowerPlus`，不再显示中文品牌名或“智能编程辅导系统”。艺术字体尚未定稿，当前使用 Avenir Next / SF Pro Rounded 回退栈作为占位。
3. 左侧栏不显示“工作台”“训练与研究”等分组标题，只保留关键功能入口。
4. 左侧栏底部不显示当前学习者、知识体系版本、模型状态等信息。
5. 不设置顶部栏。页面标题直接进入主体区域，不显示 `DASHBOARD` 等英文眉题。
6. 左侧栏固定；滚动只发生在 `main` 主体区域，不再保留顶部栏。
7. 主体使用白色气泡卡片；卡片铺满主体，但禁止大面积黑色卡面。黑色只用于文字、细边界、选中态和小面积反色动作。
8. 主体组件尽量减少重复说明小字。指标卡只保留标题与数字，建议卡只保留核心结论与操作。
9. 当前阶段只要求样式和静态模板，不要求实现新的业务功能。

## 总览页最新规则

1. 桌面标准尺寸下主体必须完整放下，不出现主体滚动条；更窄屏幕允许主体区域滚动。
2. “上午好 / 下午好 / 晚上好”标题加大，删除其下的一句说明。
3. 指标卡移除所有辅助小字。
4. 建议卡移除解释性段落，只保留知识点标签、标题和按钮。
5. 学习流程、系统状态、薄弱知识点和常用入口均按“粗标题 + 关键数据”组织，减少低优先级注释。
6. 继续使用白、黑、标准灰和细边界，不增加渐变、彩色 glow 或装饰性图标。
