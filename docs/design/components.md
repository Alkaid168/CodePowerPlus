# 组件规范

本文定义组件层。页面布局、侧栏宽度、网格列数和响应式断点由后续布局模板决定。

## 1. 按钮

| 类型 | 背景 | 文字 | 边框 | 用途 |
| --- | --- | --- | --- | --- |
| Primary | `#111111` | `#FFFFFF` | 同背景 | 页面唯一或当前区域主动作；沿用原黑底白字方案 |
| Secondary | `#FFFFFF` | `#111111` | `#D5D5D5` | 次要动作 |
| Ghost | 透明 | `#555555` | 透明 | 容器内低优先级动作 |
| Tinted | `#F5F5F5` | `#111111` | `#E0E0E0` | 筛选、辅助操作 |
| Danger | `#FFFFFF` | `#B3261E` | `#E5B7B4` | 可恢复的危险动作 |
| Danger Solid | `#B3261E` | `#FFFFFF` | 同背景 | 已确认的破坏性动作 |
| Link | 透明 | `#111111` | 透明 | 行内跳转，不使用蓝色 |

尺寸：`small 31px`、`default 38px`、`large 44px`。默认圆角 `8px`，小按钮 `6px`。图标和文字间距 `6–8px`。

交互：

- Primary 默认黑底白字，Hover 使用 `#000000`；Secondary Hover 只加深边界或变浅灰底，不使用彩色阴影。
- Press 使用 `scale(.975)`，时长 `100–120ms`。
- Disabled 使用浅灰背景、灰色文字，不响应 hover。
- 一个视觉区域最多一个 Primary 按钮。

## 2. 输入类

### 文本框、文本域、下拉框

- 高度：单行 `44px`；文本域最小 `88px`。
- 圆角：`8px`。
- 默认：白底、`2px solid #E0E0E0`。
- Hover：白底、边界 `#BDBDBD`。
- Focus：白底、只有一层 `2px solid #111111`。
- Error：白底、`2px solid #B13B36`。
- Disabled：浅灰底、浅灰边界、灰色文字。
- Placeholder 使用 `#999999`，不能替代字段标签。
- 必填项在标签旁显示 `*`，错误说明放在控件正下方。

禁止在 `:focus` 与 `:focus-visible` 上同时添加 `outline`、`box-shadow` 和加倍边框。 静态设计稿必须展示默认灰色边框；只有标注为“正在输入”的示例才可以使用黑色边框。

### 搜索框

搜索框由前置搜索图标、输入区和可选清空按钮组成。图标固定在左侧 `12px`，输入区左内边距 `34px`。清空按钮为 `25px`，只在有内容时出现。

### 代码输入框

- 外框：白色、`1px #E0E0E0`、圆角 `8px`、低阴影。
- 顶部栏：`#F5F5F5`，高度 `34px`，下方 `1px #E0E0E0`。
- 窗口点：macOS 标准 `#FF5F57`、`#FEBC2E`、`#28C840`。
- 正文：白色背景、深灰代码、黑色关键字、灰色注释。
- 行高 `1.7`，使用等宽字体。

## 3. 选择控件

### Checkbox

- 尺寸 `20px`，圆角 `4px`，可编辑时白底、`2px #BCBCBC`。
- 选中与半选为黑底白标。
- 禁用为浅灰底、浅灰边界和灰色说明。

### Radio

- 尺寸 `20px`，圆形属于语义例外。
- 未选中白底灰边，选中黑底白点。
- 同一组选项使用相同的排版间距 `10px`。

### Switch

- 尺寸 `42 × 25px`，轨道允许胶囊形。
- 关闭为 `#CFCFCF`，开启为 `#111111`。
- 圆点 `19px`，进入与切换使用 `180–220ms`。

### Slider

- 右侧未填充轨道：`2px #D7D7D7`。
- 左侧已填充轨道：`6px #111111`。
- 圆点：`20px` 黑色，外围 `3px` 白边。
- 左右轨道垂直居中，圆点位置覆盖两条轨道连接点。
- 数值必须实时可见，不使用渐变轨道。

### Stepper

- 容器为 `#F1F1F1`、圆角 `8px`、内边距 `3px`。
- 加减按钮为 `29 × 29px`、圆角 `6px`。
- 当前值为 `12px / 700`，最小宽度 `34px`。

## 4. 标签与状态

### 普通标签

- 高度 `28px`，圆角 `6px`，水平内边距 `7–9px`。
- 默认浅灰；选中可黑底白字。
- 功能色只用于语义状态。

### 判题结果

- 高度 `25px`、最小宽度 `38px`、水平内边距 `8px`、圆角 `9px`。
- 文本必须水平和垂直居中，数字使用等宽数字。
- 宽度由内容决定，不强制拉伸。
- AC：`#178451` / `rgba(38,168,107,.12)`。
- WA：`#A86500` / `rgba(244,154,24,.14)`。
- TLE：`#B13B36` / `rgba(233,79,79,.12)`。
- CE/中性：`#68778A` / `rgba(80,103,130,.09)`。
- 所有结果标签贴齐同一右侧基准线。

## 5. 导航

### 侧栏项

- 高度 `40px`，圆角 `8px`，图标 `17px`。
- 默认透明，图标为灰底灰字。
- Hover 使用白灰底，不移动超过 `2px`。
- 激活项黑底白字，右侧计数使用半透明深灰。
- 高频导航不做开合或缩放动画。

### Tabs / Segmented Control

- 容器 `#F1F1F1`，内边距 `3px`，圆角 `8px`。
- 单项高度 `32–34px`，圆角 `6px`。
- 激活项黑底白字，不使用下划线动画。

### 面包屑与分页

- 面包屑字号 `11px`，当前项黑色，父级项灰色。
- 分页按钮 `30 × 30px`，圆角 `6px`，当前页黑底白字。

## 6. 数据展示

### 表格

- 表头高度 `37px`，背景 `#F5F5F5`，字号 `10–11px`。
- 数据行高度 `40–44px`，行间使用 `1px` 浅边界。
- Hover 只改变背景，不改变行高。
- 当前行使用 `#F1F1F1`，不使用彩色边框。

### 列表行

- 最小高度 `52px`，左右内边距 `12px`。
- 结构：`32px 图标 + 自适应内容 + 右侧状态`。
- 右侧状态列使用 `max-content`，统一右对齐。
- 标题 `12px / 650`，辅助信息 `10–11px / #999999`。

### 知识树

知识树采用 OI Wiki 式 L1 顶部导航，不使用黑、灰、白分级底色，也不显示等级框。

结构与尺寸：

- 顶部横向排列所有 L1 领域；当前项使用 `#111111` 文字和底部黑线。
- 搜索框位于 L1 导航最右侧，提示文字为“搜索知识点”。
- 左侧只显示当前 L1 下的 L2/L3 节点。
- 树条目统一为白底、`1px #E8E8E8` 边界、`6px` 圆角、约 `38px` 行高。
- L3 条目整体右移 `18px`，包括箭头、圆点和左端点。
- 箭头使用 CSS 绘制，尺寸 `6px`；叶子节点使用 `4px` 圆点。
- 不显示 L1/L2/L3 文字标签。
- 选中态使用黑色边界和 `3px` 左侧黑线，不用黑色或灰色填充。
- L2/L3 叶子节点显示知识点介绍；有下级的节点只显示下级列表。
- 下级列表直接位于标题下方，不显示“下级节点”标题和顶部贯穿横线；列表项使用横向分隔线，不使用独立卡片。
- L1 详情不显示面包屑路径；L2/L3 保留路径。

## 7. 弹层

### Popover / Menu

- 圆角 `8px`，白底，`1px #E0E0E0`。
- 阴影 `0 18px 42px rgba(0,0,0,.12)`。
- 菜单项高度 `35px`，圆角 `6px`。
- Hover 使用浅灰背景，危险项使用低饱和红色。
- `transform-origin` 必须对准触发元素。

### Modal

- 圆角 `16px`，最大宽度建议 `430px`，内边距 `17px`。
- 标题和主要说明必须同时可见。
- 主按钮右置；破坏性动作需要明确文字，不只显示“确定”。
- 进入与退出保持同一路径，模态框居中弹出。

### Sheet / Drawer

- 圆角 `12px`，从固定边缘进入和退出。
- 支持中途反向，不允许锁定输入。
- 顶部保留拖动提示条，但桌面端不强制手势。

## 8. 通知与反馈

- Alert：圆角 `8px`，白底/浅状态底，图标 `22px`。
- Toast：白底或黑底均可，圆角 `8px`；使用 CSS transition，不用反复触发的 keyframes。
- Progress：高度 `6px`，黑色填充，灰色轨道。
- Skeleton：浅灰纯色脉冲，不使用渐变扫光。
- Spinner：仅用于短时任务；超过 300ms 才出现，避免闪烁。

## 9. AI 专用组件

### 分析步骤

- 每步包含编号、标题、说明和置信度。
- 编号为 `27 × 27px` 黑色方块，圆角 `5px`。
- 置信度为浅灰矩形，不使用“魔法紫”。
- 用户数据、模型推断、人工审核必须视觉上可区分。

### 知识标签选择

- 主知识点、辅助知识点和冲突状态使用不同文字，但不使用夸张色彩。
- 主知识点优先使用黑底白字。
- 辅助知识点使用灰底深字。
- 冲突状态使用低饱和红色。

## 10. 空状态与上传

- 空状态：浅灰白底、虚线边界、圆角 `10px`。
- 图标 `54px`，黑底白图形，圆角 `8px`。
- 上传区：`1px dashed #BDBDBD`，白/浅灰底，高度至少 `126px`。
- 空状态必须说明“为什么为空”和“下一步做什么”。

## 11. 组件验收清单

- 启用控件是否白底，禁用控件是否浅灰？
- 聚焦时是否只有一层黑色边框？
- 普通表面是否没有渐变和彩色光晕？
- 结果标签是否内容居中、宽度自适应、右边界统一？
- 知识树是否为整行长条，箭头和文字是否垂直居中？
- Hover 是否仅在精确指针环境触发？
- 是否包含键盘焦点、减少动态和高对比状态？



## 12. 应用外壳与总览模板补充

- 品牌区：透明 LOGO `42 × 32px` + `CodePowerPlus` 字标；字标字体待商定。
- 侧栏：只列功能入口，不显示分组说明和底部状态。
- 无顶栏：页面标题直接进入主体首行。主体使用白色气泡卡片并铺满主体，侧栏 260px、黑色文字；禁止大面积黑色卡面。
- 主体：拥有独立滚动容器；1440×900 下总览不产生滚动条。
- 总览指标卡：只显示标签和值，不显示解释句。
- 总览建议卡：只显示知识标签、主标题和操作按钮，不显示段落说明。
- 总览次级卡：使用“标题 + 数值/进度”结构，不重复解释流程。

## 13. XEPT 轻量白卡（2026-09-14 最新）

- 总览主建议卡：单一白色横向卡面，只保留标签、标题和操作按钮；不放右侧内嵌卡片、品牌图示或掌握度环。
- 主按钮：沿用黑底白字原有方案；Hover 使用 `#000000`，Press `scale(.975)`。
- Secondary：白底、`1px #BDBDBD` 边界；Hover 只变为 `#F1F1F1`。
- 卡片：`12px` 圆角、`1px #E0E0E0` 边界、低阴影和较大留白，不使用黑色 Hero。
- 总览指标卡和次级卡 Hover 只做 `translateY(-2px)`、边界加深和轻微阴影，不使用彩色 glow。


### L1 知识插画

- 9 个 L1 各自使用一张代码原生 SVG 线条插画，不使用位图。
- 画布 `240×160`，透明背景，线条统一使用 `currentColor`，默认为 `#111111`。
- 主结构约 `2px`，辅助结构约 `1–1.5px`；不用彩色、渐变或阴影。
- L1 详情不显示下级目录，插画最大宽度 `380px`、最大高度 `270px`。
