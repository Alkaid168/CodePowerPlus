# 视觉基础

## 1. 参考来源与判定

圆角与控件基准来自对 `https://xept.online/register` 的浏览器计算样式检查，记录于 2026-09-13：

| 元素 | Xept 实测值 | 本项目采用值 |
| --- | --- | --- |
| 页面底色 | `#f5f5f5` | `#f5f5f5` |
| 卡片背景 | `#ffffff` | `#ffffff` |
| 大卡片圆角 | `16px` | `16px` |
| 输入框圆角 | `8px` | `8px` |
| 输入框边框 | `2px solid #e0e0e0` | `2px solid #e0e0e0` |
| 主按钮圆角 | `8px` | `8px` |
| 阴影 | 大面积低透明度黑色 | 低透明度黑色，不使用彩色阴影 |

参考只用于控件尺度。CodePowerPlus 不复制 Xept 的品牌、文案和业务布局。

## 2. 色彩

### 中性色

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F5F5F5` | 页面底色 |
| `surface` | `#FFFFFF` | 卡片、输入框、弹层、可编辑区域 |
| `surfaceSubtle` | `#FAFAFA` | 次级分区、空状态、代码行导航 |
| `surfaceMuted` | `#F1F1F1` | 导航激活段、分组底色 |
| `border` | `#E0E0E0` | 默认边界 |
| `borderStrong` | `#BDBDBD` | 悬停边界、强调分隔 |
| `text` | `#111111` | 主文字、主按钮背景与边界 |
| `textSecondary` | `#666666` | 说明文字 |
| `textTertiary` | `#999999` | 占位、时间、辅助信息 |
| `disabledFill` | `#F5F5F5` | 禁用控件 |
| `disabledBorder` | `#E8E8E8` | 禁用边界 |
| `disabledText` | `#999999` | 禁用文字 |

### 功能色

功能色只用于状态，不做装饰底色。

| 状态 | 前景 | 背景 |
| --- | --- | --- |
| AC / Success | `#178451` | `#EDF7F0` |
| WA / Warning | `#A86500` | `#FBF5E9` |
| TLE / Danger | `#B13B36` | `#FDF1F0` |
| Neutral / CE | `#666666` | `#F2F2F2` |
| Info | `#333333` | `#F5F5F5` |

### 禁止项

- 禁止 `linear-gradient`、`radial-gradient`、渐变文字和高饱和光晕。
- 禁止把蓝色作为默认品牌主色；主行动沿用黑底白字，Hover 使用纯黑色。
- 禁止大面积黑色卡面；黑色只用于文字、细边界、选中态和小面积反色动作。
- 禁止大面积使用状态色。
- 禁止在同一个控件中同时使用彩色边框和彩色阴影。

## 3. 字体

字体栈：

```css
-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC",
"Microsoft YaHei", "Noto Sans SC", sans-serif;
```

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | `28px` | `720` | `1.15` | 页面主标题 |
| Title | `22px` | `700` | `1.2` | 页面标题 |
| Section | `16px` | `680` | `1.3` | 卡片标题 |
| Body | `14px` | `500` | `1.55` | 正文 |
| UI | `12px` | `600` | `1.4` | 控件、表格、导航 |
| Caption | `11px` | `500` | `1.4` | 时间、说明、占位 |
| Mono | `12px` | `500` | `1.7` | 代码、算法名称 |

知识树使用 `12.5px / 560` 的文字，不再使用小号粗体。数字统一开启 `font-variant-numeric: tabular-nums`。

## 4. 间距

使用 4px 基网格：

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `space-1` | `4px` | 图标与文字的内聚间距 |
| `space-2` | `8px` | 按钮内、紧凑控件间距 |
| `space-3` | `12px` | 表单行、卡片内部 |
| `space-4` | `16px` | 卡片内边距 |
| `space-5` | `20px` | 分区间距 |
| `space-6` | `24px` | 页面模块间距 |
| `space-8` | `32px` | 大区块间距 |

## 5. 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-control` | `8px` | 输入框、按钮、下拉框 |
| `radius-small` | `6px` | 小按钮、导航项、树行 |
| `radius-card` | `12px` | 普通卡片、表格容器 |
| `radius-panel` | `16px` | 大面板、模态框 |
| `radius-status` | `9px` | AC、WA、TLE 等结果框 |
| `radius-level` | `5px` | 知识树 L1/L2/L3 标记 |

例外：开关轨道、头像、滑动条圆点允许使用圆形；除此之外不要把普通卡片做成胶囊。

## 6. 阴影与边界

- 默认卡片依靠 `1px #E0E0E0` 边界表达层级，阴影只用于轻微浮起。
- 普通卡片阴影不超过 `0 10px 28px rgba(0,0,0,.055)`。
- 弹层阴影不超过 `0 18px 42px rgba(0,0,0,.12)`。
- 禁止蓝紫阴影、外发光和厚重的玻璃光晕。
- 所有表面优先使用纯白；不把半透明玻璃作为普通内容卡片。

## 7. 统一状态

| 状态 | 规则 |
| --- | --- |
| Default | 白底、`#E0E0E0` 边界、黑色主文字 |
| Hover | 背景可变为 `#F5F5F5`，边界可为 `#BDBDBD`，最多位移 `1px` |
| Focus | 单层 `2px #111111` 边界；禁止再叠加 outline 或 box-shadow |
| Active | `transform: scale(.975)`，时长 `100–120ms` |
| Selected | 黑白反转或浅灰底，不新增彩色光晕 |
| Disabled | `#F5F5F5` 背景、`#E8E8E8` 边界、`#999999` 文字 |
| Error | `2px #B13B36` 边界和白底，错误说明使用红色文字 |
| Loading | 只保留必要旋转，不移动周围内容 |

## 8. 输入框边界规则

- 所有输入类控件默认使用 `2px solid #E0E0E0`。
- 只有用户真实聚焦、正在输入时，边框才切换为 `2px solid #111111`。
- 设计稿的静止状态不得保留 `.focus`，否则会被误读为默认黑色边框。
- Focus 不得同时增加 outline、box-shadow 或第二层边界。

## 9. 图标

- 使用 16px 或 18px 线性图标，线宽 1.5–1.75px。
- 视觉中心必须与文字中线对齐，不依赖字体图标垂直对齐。
- 知识树箭头使用 CSS 边界绘制，避免不同字体的箭头位置漂移。
- 纯图标按钮必须有 `aria-label` 和可见聚焦状态。



## 10. 品牌与英文标题

- 品牌标志使用透明 PNG，不把白色原图直接放在页面中。
- 英文品牌名统一写法：`CodePowerPlus`，大小写固定。
- 艺术字体尚未确定；当前 CSS 变量为 `--wordmark-font`，后续只改字体，不改品牌文案。
- 页面顶栏不用英文眉题，标题层级直接从中文大标题开始。

## 11. XEPT 轻量白卡补充（2026-09-14）

- 白色是普通内容面的默认底色；黑色不用于大面积卡片背景。
- Primary 按钮沿用原方案：黑底、白字、黑色边界；Hover 使用纯黑色。
- 黑色保留给标题、数字、选中态、边界和少量动作反馈，避免主页面出现黑块压过内容。
- 卡片继续依靠白色、留白和细边界分层；总览主卡不再使用右侧浅灰内嵌卡片或品牌图示。
