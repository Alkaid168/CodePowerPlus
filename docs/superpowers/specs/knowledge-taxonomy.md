# 题目知识体系标准

## 来源与范围

体系参考 OI-Wiki 的栏目组织方式（语言基础、算法基础、搜索、动态规划、字符串、数学、数据结构、图论、计算几何、杂项等），保留 OI 竞赛中稳定的概念层级。OI-Wiki 作为初始参考来源，项目维护自己的版本，不直接把外部目录当作运行时依赖。

## 层级

- L1 领域：如“数学”“图论”“动态规划”。
- L2 分支：如“数学/数论”“图论/最短路”“动态规划/背包 DP”。
- L3 知识点：如“数学/数论/唯一分解定理”“图论/最短路/Dijkstra 算法”。
- L4 技巧（可选）：只有在题目确实需要时使用，如“数学/数论/唯一分解定理/试除法实现”。

每个节点有稳定 `id`、中文名称、英文 slug、层级、父节点、简介、前置节点和状态；删除节点只能标记废弃，不能复用 ID。题目至少关联一个 L2 或 L3 节点，允许关联多个节点，但同一分支最多一个主节点，避免泛化打标。

## 标注规则

AI 只能从当前版本的节点清单中选择 ID，禁止创造新标签、修改名称或返回自由文本标签。返回主知识点、辅助知识点、每个节点的证据句和置信度；无法确定时返回候选节点和低置信度，由人工确认。领域节点只用于聚合统计，不作为唯一题目标签。

标注依据按优先级为：核心算法/定理 > 必要数据结构 > 关键实现技巧 > 题目背景。题面只提到某概念但解法不需要时不得标注。题目分析保存 `taxonomy_version`，体系变更后可以重新分析和比较版本。

## 初始示例

```text
数学 (L1)
└─ 数论 (L2)
   └─ 唯一分解定理 (L3)
图论 (L1)
└─ 最短路 (L2)
   └─ Dijkstra 算法 (L3)
动态规划 (L1)
└─ 背包 DP (L2)
   └─ 01 背包 (L3)
```

## 质量控制

体系文件使用 JSON Schema 校验；提交前检查父节点存在、层级连续、ID 唯一、无环、slug 唯一。模型输出必须通过节点 ID 校验；未知 ID 直接拒绝并进入重试/人工复核，不写入题目分析。
