# 题目知识体系规范（标签词表）

## 定位

知识体系服务于“给题目打标签”：题目分析选标签、能力画像按标签汇总、推荐与学习路径按标签选目标。它不是教材，也不是学习依赖图，所以节点只保留名称与层级，其他信息（难度、典型算法、讲解、前置）一律不属于这里。

## 来源与范围

结构与名称取自 OI Wiki（oi-wiki.org）的栏目导航，2026-09-13 抓取；不含栏目简介、赛事信息、工具软件与语言基础（Hello World、变量、函数、编译调试、C++ 特性等），因为这些不可能成为一道题的考察标签。实现细节（例如“试除判素数”）写进证据句，不拆成节点。

## 结构

- 只用 L1/L2/L3，不建 L4。
- L1 是领域，只做聚合，不能作为标签。
- L2 既可以是分支（挂 L3），也可以是二级知识点（无下级）。
- L3 是三级知识点。
- 节点字段固定为 `id`、`name`、`level`、`parent_id`；`id` 由 OI Wiki 栏目路径推导并保持稳定，`name` 全树唯一。

## 标注规则

AI 只能从当前版本的 L2/L3 里选 ID，不能创造标签；主标签在同一 L2 分支最多一个；不要同时标祖先与后代；每个标签附题面或解法中的证据句与 0..1 置信度；分析保存 `taxonomy_version`。服务端校验失败直接拒绝，并把失败交给人工确认，不写入自由标签。

## 质量与版本

JSON Schema + 业务校验（ID 唯一、层级连续、父节点存在）；目录变更需要题目需求驱动，升版本号并保留快照；删除节点在新版本移除并记录原因，旧分析保留旧版本号。禁止脚本批量生成空壳节点。
